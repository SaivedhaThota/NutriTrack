# 🥗 NutriTrack – Nutritional Estimation System

NutriTrack is an intelligent nutrition and food recommendation platform designed to help users monitor their dietary habits, estimate nutritional intake, and make healthier food choices through personalized recommendations.

The system allows users to create and manage their personal profiles by providing details such as age, gender, weight, height, dietary preferences, and health goals. Based on this information, NutriTrack generates personalized food recommendations tailored to the user's nutritional requirements and lifestyle objectives.

### Key Features

#### 👤 User Profile Management

* Create and manage personalized user profiles.
* Store health-related information including age, gender, weight, height, and fitness goals.
* Support customized dietary preferences and nutritional targets.

#### 🍽️ Food Search System

* Search for a wide variety of food items.
* Retrieve detailed nutritional information for each food item.
* Display calorie count, protein, carbohydrates, fats, vitamins, and other essential nutrients.

#### 🤖 Personalized Food Recommendations

* Recommend food items based on user profile data.
* Suggest healthier alternatives according to dietary goals.
* Provide nutrition-aware recommendations for weight management and healthy eating.

#### 🔥 Calorie Estimation

* Calculate estimated calorie intake for selected food items.
* Help users track daily calorie consumption.
* Assist users in maintaining calorie goals for weight loss, maintenance, or muscle gain.

#### 📊 Nutritional Value Analysis

* Analyze the nutritional composition of food items.
* Display macronutrients and micronutrients in an easy-to-understand format.
* Enable users to make informed dietary decisions through data-driven insights.

#### 📈 Data Visualization

* Visualize nutritional information using interactive charts and graphs.
* Compare calorie and nutrient values across different foods.
* Improve user understanding through graphical representations.

### Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Data Visualization Libraries

### Project Outcome

NutriTrack helps users develop healthier eating habits by combining nutritional analysis, calorie estimation, personalized food recommendations, and data-driven insights within a user-friendly platform.
